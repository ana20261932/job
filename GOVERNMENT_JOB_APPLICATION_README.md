## 📋 APPLICATION SUBMISSION PROCESS

### **STEP 1: DOCUMENT PREPARATION**
Each application requires:

**✅ Required Documents**:
1. **Z83 Form** (generated - see individual PDFs)
2. **Detailed CV** (your improved CV v3)
3. **Certified Copy of ID** (only if shortlisted for interview)
4. **Certified Qualifications Certificates** (only if shortlisted for interview)

**✅ NOT Required Initially**:
- Certified documents are ONLY requested if you are **shortlisted for interview**
- Submit only Z83 form + CV with initial application

### **STEP 2: APPLICATION METHOD**

#### **OPTION A: ONLINE SUBMISSION**
Most departments accept online applications through their careers portals:
- Visit each department's careers website
- Look for "Apply Now" or "Submit Application" button
- Upload Z83 form (PDF) and CV (PDF)
- Enter reference number (e.g., DPSA/IT/2026/001)

#### **OPTION B: EMAIL SUBMISSION**
For departments without online systems:
- **Email Format**: Include subject line with reference number
- **Email to**: Use department-specific email addresses above
- **Include**: Z83 form + CV as attachments
- **File naming**: `[ReferenceNumber]_Z83_Form.pdf`

#### **OPTION C: PHYSICAL SUBMISSION**
For traditional departments:
- **Address**: Use department headquarter addresses above
- **Method**: Registered mail or hand delivery
- **Envelope**: Clearly mark with reference number
